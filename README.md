# Бок о бок

Веб-сервис визуализации прогресса научных проектов для инвесторов, основателей, сотрудников фонда и главного администратора.

## Запуск

```bash
python3 backend/server.py 5188
```

Откройте `http://127.0.0.1:5188/index.html`.

После первого запуска создайте настоящего главного администратора:

```bash
python3 backend/create_admin.py --name "Имя Фамилия" --email admin@example.ru --phone +79991234567
```

При локальном запуске на `127.0.0.1` вход временно работает по паролю без SMS. На сервере этот режим можно включить через `BOKOBOK_DISABLE_SMS_2FA=1` только за доверенным HTTPS-прокси. Чтобы вернуть SMS, установите `BOKOBOK_DISABLE_SMS_2FA=0`.

## База данных

SQLite-база автоматически создаётся в `data/bokobok.db` без пользователей, проектов и других продуктовых записей. Миграции находятся в `db/migrations`, описание модели и API — в `db/README.md`.

Материалы этапов (документы, фото и видео до 50 МБ за файл) сохраняются в `data/uploads/`. Для переноса или резервного копирования проекта нужны и база, и эта папка.

Для отдельного демонстрационного основателя и проекта с 6 событиями выполните `python3 -B backend/seed_demo.py`. Команда создаёт данные только по явному запуску, не меняет существующие проекты и выводит пароль один раз. Повторный запуск не дублирует записи и не сбрасывает пароль. Демопроект остаётся черновиком и помечен как вымышленный.

```bash
python3 backend/db.py
python3 -m unittest -v tests.test_database
```

Приложение включает версионные деревья прогресса, этапы и доказательства, модерацию публикаций, вопросы инвесторов, уведомления, сессии с SMS-2FA и аудит действий.
